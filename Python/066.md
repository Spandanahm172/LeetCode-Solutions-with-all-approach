# Plus One

## Solution 
```python
class Solution:
    def plusOne(self, digits: list[int]) -> list[int]:

        if len(digits)==0:
            return [1]

        if digits[-1]!=9:
            digits[-1]+=1
            return digits

        if digits[-1]==9 :
            return self.plusOne(digits[:-1]) + [0]
```
