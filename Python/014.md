# 14. Longest Common Prefix

## Solution 1
```python
class Solution:
    def longestCommonPrefix(self, strs: list[str]) -> str:

        prefix = strs[0]

        for i in range(1, len(strs)):
            match = strs[i]
            while prefix != match[:len(prefix)] :
                prefix = prefix[:-1]
   
        return prefix
```

## Solution 2

```python
class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        if len(strs) == 0:
            return ""
        prefix = strs[0]
        for i in range(1, len(strs)):
            while strs[i].find(prefix) != 0:
                prefix = prefix[0 : len(prefix) - 1]
                if prefix == "":
                    return ""
        return prefix
```

## Solution 3

```python
class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        if strs == None or len(strs) == 0:
            return ""
        for i in range(len(strs[0])):
            c = strs[0][i]
            for j in range(1, len(strs)):
                if i == len(strs[j]) or strs[j][i] != c:
                    return strs[0][0:i]
        return strs[0]
```
