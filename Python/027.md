# Remove Element

## Solution 1
```python 
class Solution:
    def removeElement(self, nums: list[int], val: int) -> int:
        insert = 0 
        
        for i in range(len(nums)):
            if nums[i]!= val:
                nums[insert] = nums[i]
                insert+=1
            
        return insert
```

## Solution 2
```python
class Solution:
    def removeElement(self, nums: List[int], val: int) -> int:
        i = 0
        n = len(nums)
        while i < n:
            if nums[i] == val:
                nums[i] = nums[n - 1]
                n -= 1
            else:
                i += 1
        return n
```
